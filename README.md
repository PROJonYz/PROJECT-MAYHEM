# PROJECT MAYHEM

A third-person 3D co-op action roguelite in development using **Godot 4.7.2 Stable** and GDScript.

## Current state: v0.1 single-player combat prototype

The initial Godot prototype is being committed to this repository. It provides an arena, controllable character, shooting, enemy waves, XP choices, a boss and basic saved gold.

**Not yet implemented:** online co-op, matchmaking, shared progression, loot inventory, character classes, and hub. Those are planned milestones.

## Project goals

- 1–4 player cooperative PvE
- Randomized loot with rarity and build-defining effects
- Stackable in-run upgrades and synergies
- Regional bosses and cooperative encounters
- Permanent unlocks, characters and shared hub

## Getting started

1. Clone or download this repository.
2. In Godot **4.7.2**, select **Import** and choose `project.godot`.
3. Run the project with **F5**.
4. WASD moves; mouse aims; left-click shoots; Esc releases/captures the cursor; R restarts the run.

## Workflow

Use GitHub issues to track features. Development uses feature branches and pull requests once the initial baseline is validated.

This project has no third-party art. The initial prototype uses primitive meshes.

> Early prototype: scripts still require an in-editor runtime test on Godot 4.7.2. Open an issue with exact error messages when testing reveals problems.
